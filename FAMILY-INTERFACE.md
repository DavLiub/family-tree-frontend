# Интерфейс семейного сайта

## Редактирование карточки

1. Открыть человека и нажать нижний карандаш для включения режима редактирования страницы.
2. Нажать «Редактировать карточку» рядом с ФИО.
3. Изменить имя, фамилии или пол и нажать «Сохранить».

Отмена закрывает форму без записи в API. При ошибке форма остаётся открытой.
Сохранение оставляет дополнительные имена, происхождение фамилий, ссылки на события,
родственников, фотографии, заметки, источники и приватность без изменений.
Даты и места редактируются в разделе событий, дополнительные имена — в разделе имён.

Перед сохранением карточка повторно загружается. Если её содержимое изменилось,
форма предлагает загрузить данные заново; введённые изменения при этом сбрасываются.
Это предварительная проверка, а не атомарная блокировка: одновременные изменения
между проверкой и PUT требуют поддержки со стороны API.

## Проверки и публикация

GitHub workflow `test.yml` запускает lint, сборку, проверку типов и unit-тесты
при push в любую ветку, в PR и вручную. Тестовые данные вымышленные;
тесты не подключаются к рабочему дереву и не изменяют базу.

Штатные workflows публикации Docker-образов ограничены исходным репозиторием:
наша версия не публикует образы в registry разработчиков Gramps.

## Сборка и публикация на VPS

```bash
cd /opt/sites/family-tree/frontend
./scripts/deploy-interface.sh
```

Скрипт устанавливает зависимости из package-lock.json и собирает интерфейс
в одноразовом контейнере Node.js 22, закреплённом по digest. Лимиты сборки:
1536 МиБ памяти, 3072 МиБ вместе со swap, 1 CPU; heap Node.js ограничен 1024 МиБ,
минификация использует один worker.
Тесты не запускаются. Сборка включает штатную компиляцию TypeScript.

Готовая сборка копируется в отдельный каталог `frontend-releases` рядом с Compose.
Она подключается read-only к `/app/static` официального веб-контейнера Gramps.
Пересоздаётся только сервис grampsweb: его существующие лимиты 768 МиБ и 0.75 CPU,
localhost-порт 5055, образ, базы и прочие volumes сохраняются. Celery и Valkey
не перезапускаются. Скрипт проверяет конфигурацию Compose, index.html и HTTP 401
неавторизованного API. При неудачном запуске возвращает предыдущую конфигурацию.

Только собрать, без публикации:

```bash
./scripts/build-interface.sh
```

Откатить последнюю публикацию:

```bash
./scripts/rollback-interface.sh
```

Последняя предыдущая конфигурация сохраняется в `compose.before-interface.yaml`.
Сборки не удаляются автоматически. Это откат интерфейса, а не резервная копия БД.
Для нестандартного каталога Compose задайте `FAMILY_TREE_DIR`.

Исходники опубликованной сборки доступны по `/family-interface-source.tar.gz`.
После публикации обновите страницу; service worker может сначала предложить
обновление приложения. Скрипты не делают commit, push или merge.
